# Конвейер ассетов

## Принципы

1. По возможности генерировать ассеты средствами Roblox Studio и Luau.
2. Использовать Blender, когда нужны органическая геометрия, сложные UV, запекание текстур или полноценный риггинг.
3. Каждый ассет хранить отдельно: генератор, исходные материалы, превью и инструкция.
4. Генераторы должны быть повторяемыми: одинаковая конфигурация создаёт одинаковый результат.
5. Не загружать неизвестные Toolbox-модели и сторонние пакеты автоматически.

## Добавление нового ассета

- Создать генератор в assets/<category>/<name>.luau.
- Дать модели понятные имена и сгруппировать её в один Model.
- Отключить коллизии у декоративных деталей по умолчанию.
- Вынести масштаб, позицию и палитру в блок CONFIG.
- Проверить ассет в Studio на целевом масштабе и на слабом устройстве.
- Обновить README с инструкциями запуска.
