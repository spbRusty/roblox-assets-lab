# Roblox Assets Lab

Набор процедурных игровых ассетов и инструментов для Roblox Studio.

## Первый ассет: модульная винтовка

Генератор декоративной игровой винтовки R-01 создаёт модель непосредственно в Roblox Studio из отдельных деталей: корпус, ствол, приклад, рукоять, магазин, планки, прицельные приспособления, оптический модуль, крепёж и вентиляционные прорези.

Это визуальный ассет, а не готовая боевая система: стрельба, перезарядка и анимации пока не входят в комплект.

## Установка

1. Склонируй репозиторий на Windows: git clone https://github.com/spbRusty/roblox-assets-lab.git
2. Открой Roblox Studio и нужный проект.
3. Открой View → Command Bar.
4. Открой файл assets/weapons/r01_rifle.luau, скопируй весь код и вставь его в Command Bar.
5. Нажми Enter. Модель R01_Rifle появится в Workspace около точки (0, 5, 0).
6. Перемести модель, если нужно, и сохрани проект.

Генератор запускается в режиме редактирования Studio. Повторный запуск удаляет предыдущую модель с именем R01_Rifle и создаёт её заново.

## Настройка

В начале скрипта есть блок CONFIG: там можно изменить позицию, масштаб, основные цвета и имя модели.

## Структура

- assets/weapons/r01_rifle.luau — генератор винтовки
- docs/ASSET_PIPELINE.md — правила добавления новых ассетов

## Ограничения

- Геометрия собрана из стандартных деталей Roblox, поэтому ассет не требует Blender или внешних плагинов.
- Детали объединены в Model и имеют осмысленные имена.
- Скрипт не загружает сторонние модели, текстуры или пакеты.
- Это стартовая версия для проверки конвейера. Перед использованием в большой игре нужно проверить масштаб, коллизии и производительность в целевом проекте.
